v0.4.27 (2026-08-09)

- Expanding the playlist reserves dedicated layout width instead of overlaying the player.
- Collapsing the playlist restores the full player width and increases its height using the current video's aspect ratio.
- Player dimensions are recalculated when resizing the window or switching between landscape and portrait media.
- Added lightweight 120–170ms size and opacity animations for playlist expansion and collapse.

- Cached cards now render progressively in batches of 32 so the window becomes responsive sooner.
- Fast library synchronization begins in the background after cached content is visible.
- Fullscreen mode now preserves and restores the playlist state correctly.
